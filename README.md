<h2>Objetivo</h2>
O Gestock é um sistema de gestão de vendas que foi criado para facilitar as vendas e a gestão do estoque, otimizando o trabalho dos usuários e mantendo a organização dos produtos e clientes.
<br>
<h2>Funcionalidades</h2>
Cadastro, exclusão, atualização e consulta de Produtos<br>
Cadastro, exclusão, atualização e consulta de Vendas<br>
Cadastro, exclusão, atualização e consulta de Clientes<br>
Cadastro, exclusão, atualização e consulta de Usuarios
